description: Set up, upgrade or check an LLM Wiki G² vault. Detects the vault state and takes the right path.
---

Detect the state of this vault and act accordingly, following the `g2-setup` skill.

1. Determine whether this folder is **empty**, an **existing LLM Wiki**, or **already G²**:

```bash
find . -name '*.md' -not -path './.*' | wc -l
grep -rl 'derivation_depth' . --include='*.md' 2>/dev/null | head -1
test -d .git && echo "git: yes" || echo "git: no"
test -f CLAUDE.md && echo "has CLAUDE.md"
```

2. Then:
   - **Empty** → scaffold the structure, ask the user what the vault is for.
   - **Existing wiki** → follow the `g2-migrate` skill. Dry run first, show the report,
     get consent before writing anything.
   - **Already G²** → run `build-edges.py` and `wq.py lint`, report health.

Never overwrite an existing `CLAUDE.md`, never delete anything, never rewrite the user's prose.
